# @a2uiverse/sdk

The contracts A2UIVerse's parts agree on — what the orchestrator adds around the A2UI it relays to the client, what a catalog artifact is, what the marketplace serves and takes — and the checks every side runs over them, plus generic A2UI tools. The orchestrator, the client, the shell catalog, Stellify, the marketplace and the registry snapshot all build on it; no vendor app needs to.

## Install

Inside this monorepo:

```json
"@a2uiverse/sdk": "workspace:*"
```

Outside it, as a git dependency:

```json
"@a2uiverse/sdk": "github:retz8/a2uiverse#path:packages/sdk/js"
```

One entry point, `@a2uiverse/sdk`. ESM, runs in Node and the browser.

## Quick start

**Stamp an event, read the stamp back**

```ts
import {STAMP_KEY, namespaceSurfaceId, readStamp} from '@a2uiverse/sdk';

// orchestrator
event.metadata = {...event.metadata, [STAMP_KEY]: {source: 'gmail', role: 'fragment'}};
namespaceSurfaceId('gmail', 'inbox'); // "gmail:inbox"

// client
const stamp = readStamp(event.metadata); // {source: 'gmail', role: 'fragment'} | undefined
```

**Validate an A2UI v1.0 tree against a pruned catalog**

```ts
import {createA2uiValidator, formatA2uiFinding, pruneCatalog} from '@a2uiverse/sdk';

const catalog = pruneCatalog(catalogJson, {
  components: ['Column', 'Text', 'Table', 'TableRow', 'DerivedValue'],
  functions: ['value', 'min'],
});
// Several catalogs, each component judged against the one it names; the first is the default
// of a surface the payload updates without creating it.
const validator = createA2uiValidator({catalogs: [catalog]});

const findings = validator.validate([
  {version: '1.0', createSurface: {surfaceId: 's', catalogId}},
  {version: '1.0', updateComponents: {surfaceId: 's', components}},
]);
console.log(findings.map(formatA2uiFinding));
```

What the platform writes itself can also be held to the v1.0 JSON schemas, which refuse a binding written `path`, a call written `call` and an `updateDataModel` with no `value`, all of which the release accepts:

```ts
import {createSchemaFormCheck} from '@a2uiverse/sdk';

createSchemaFormCheck({catalog}).agentToRenderer(messages); // [] when every message holds
```

**Read and check a synthesis payload**

```ts
import {readSynthesis, validateSynthesisPayload, walkModel} from '@a2uiverse/sdk';

const checked = validateSynthesisPayload(readSynthesis(event.metadata));
if (checked.ok) {
  const {leaves, claims} = walkModel(checked.value.dataModel);
} else {
  console.error(checked.errors); // one line per finding
}
```

**Check an app's catalogs at install**

```ts
import {
  catalogsOutside,
  checkCoverage,
  coverageErrors,
  entitlementOf,
  readSupportedCatalogIds,
  rendererCapabilities,
} from '@a2uiverse/sdk';

const declared = readSupportedCatalogIds(card); // the ids under the card's v1.0 A2UI extension entry, read flat
if (declared.ok) {
  const handed = [githubCatalogId]; // the catalog id of each artifact handed with the card
  const errors = coverageErrors(checkCoverage(declared.value, handed));
  // [] when every declared id is handed or public and every handed id is declared
  const entitlement = entitlementOf(handed); // [the basic catalog's id, githubCatalogId]: what the app may paint in
  rendererCapabilities(entitlement); // {"1.0": {supportedCatalogIds: [...]}}: what the hub advertises
  catalogsOutside(paint, entitlement); // [] when every place the paint names a catalog is inside
} else if (declared.otherVersions) {
  // the card declares A2UI, and not v1.0: {versions: ['v0.8', 'v0.9'], allOlder: true}
}
```

**Verify a catalog artifact's files**

```ts
import {artifactIdOf, validateArtifactDescriptor, verifyArtifactFiles} from '@a2uiverse/sdk';

const descriptor = validateArtifactDescriptor(
  JSON.parse(new TextDecoder().decode(descriptorBytes)),
);
if (descriptor.ok) {
  await verifyArtifactFiles(descriptor.value, files); // [] when every listed file matches its hash and nothing else is there
  await artifactIdOf(descriptorBytes); // "sha256-o0lcA0wt…": the artifact's id, the descriptor's hash spelled URL-safe
}
```

**Resolve a pointer**

```ts
import {locatePointer, resolvePointer} from '@a2uiverse/sdk';

resolvePointer(model, '/threads[id="1a06f2"]/time');
// {found: true, value} | {found: false, reason: 'missing' | 'ambiguous' | 'null' | 'positional'}

locatePointer(model, '/threads[id="1a06f2"]/time');
// the same, plus `path`: the concrete path with positions, e.g. "/threads/3/time"
```

Four things worth knowing about the checks:

- The index entry's `card` is typed `object` and the entry's schema requires nothing of it: it is the agent's card as served, in the shape of the A2A version it was written in. A field is reached through the card package's `readCard` ([`packages/card`](../card/README.md)), and the published version is `publishedVersionOf(entry)`. The functions here that take a card (`readSupportedCatalogIds`, `aheadOfStore`, `smokeWords`, `checkSignInAnswer`) take the read card, through structural types, so the sdk depends on no A2A package.
- `validateSynthesisPayload` checks the payload's shape — every leaf a formula, every match claim relating two refs in two different sources, every sort well formed. Whether a relation actually holds is the caller's.
- `checkAdditiveEvolution` compares the two schema files as the gate reads them, a `$ref` as a string, never resolved; a keyword it doesn't know is ignored, never refused. `checkPaint` judges the stamp first: an answer stamped other than `1.0` is in another version, and nothing else is judged. It then groups the messages by surface, checks every catalog each surface names against the entitlement, and validates each surface over the app's entitled catalogs, each component against its own, judging each tree as it stands when the answer ends — each component's last copy, only what the root reaches — so an agent streaming its tree as it's written passes when the finished tree does; it hands that settled paint back beside its findings, the form a preview stores.
- `credentialInputIn` matches the terms as whole words, case-insensitively, against painted components' types, property names, and the literal values their catalog declares as options — `enum` and `const` strings, never descriptions; free text and the data model are not read. `pin` alone is allowed, `pin code` is not.

## Commands

```bash
pnpm --filter @a2uiverse/sdk build | typecheck | test | lint
pnpm --filter @a2uiverse/sdk sync-a2ui-spec    # copy a2ui-spec/ from the A2UI fork at the pinned commit
```

`a2ui-spec/` is never edited by hand. It is held at `7a776e7a4`, the commit `@a2ui/web_core` 0.16.1 was released from, and `a2ui-spec/UPSTREAM.json` records the commit. `A2UI_REPO` names the fork's path when it is not the monorepo's sibling `../A2UI`, as from a worktree; `A2UI_REF` names another commit.
