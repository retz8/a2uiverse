# Security

## Reporting a vulnerability

Report it privately through [GitHub's private vulnerability reporting](https://github.com/retz8/a2uiverse/security/advisories/new), never in a public issue or discussion. Say what is affected, how to reproduce it, and what it lets someone do.

Reports are acknowledged as soon as the maintainer can; there is no fixed response time.

## Scope

This repo: the client, the orchestrator, the marketplace, `sdk` and `shell-catalog`. The vendor apps live in [a2uiverse-apps](https://github.com/retz8/a2uiverse-apps), which has its own policy.

A2UIVerse runs as local processes and is not deployed anywhere. Only `main` is supported.
