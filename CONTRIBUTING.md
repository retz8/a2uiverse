# Contributing

A2UIVerse is in active development and isn't done: the composed screen and the ecosystem around it, apps published, installed and signed in to through the shell, are built, and [Where it's headed](README.md#where-its-headed) says what's next. Feedback from anyone interested in it is welcome.

## Feedback and questions

Start a thread in [Discussions](https://github.com/retz8/a2uiverse/discussions): an idea, a question, what you tried and how it went, what didn't make sense. Questions about the design are welcome there too. [SPEC.md](SPEC.md) is the design, and [docs/design](docs/design) walks through each part.

## Bugs

Open an [issue](https://github.com/retz8/a2uiverse/issues/new/choose) with how you ran it (the replay, the apps in deterministic mode, or live), what you expected, and what happened.

## Code changes

Open a discussion or an issue before writing code, so the change is agreed on first. The gates, `pnpm verify`, must be green on a pull request. [Try it](README.md#try-it) covers the setup.

## Security

Report a vulnerability privately, as [SECURITY.md](SECURITY.md) describes, never in an issue or a discussion.

## Code of conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
